# Third-party notices

This file lists externally sourced content shipped with Loggy. Update it when adding bundled fonts, images, or data snapshots.

## Muscle / anatomy assets

When you add schematic or anatomical images (e.g. from Wikimedia Commons), record:

- File name in the repository  
- Source URL  
- License (e.g. CC BY-SA 4.0)  
- Required attribution text for an in-app About / Credits screen  

No runtime-downloaded muscle imagery is used by default; assets are expected to be committed to the repo after license review.
